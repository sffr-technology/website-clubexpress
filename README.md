# SFFR ClubExpress HTML modules

This repository stores the editable inner HTML used by custom-content pages on [sffr.org](https://www.sffr.org/). Each `.html` file is an HTML fragment: it intentionally omits `<!doctype>`, `<html>`, `<head>`, `<body>`, navigation, footer, and the surrounding ClubExpress layout.

## Structure

- `modules/home/` — homepage content
- `modules/weekly-runs/` — recurring run and walk pages
- `modules/membership/` — membership pages
- `modules/about/` — board and club history
- `modules/race-circuit/` — race circuit and leaderboard content
- `modules/programs/` — seasonal training programs
- `inventory/pages.json` — source URL and module metadata

## Editing workflow

1. Find the page in `inventory/pages.json`.
2. Edit its HTML fragment under `modules/`.
3. Paste the fragment into the matching ClubExpress custom-content module.
4. Update `lastReviewed` in the inventory after verifying the live page.

Images hosted in ClubExpress are represented with descriptive placeholders where the public crawler did not expose a stable asset URL. Replace those comments with the current ClubExpress image markup when publishing.

## Exclusions

ClubExpress-generated pages (event calendar/details, contact form, login, membership signup, directory, and account screens) are not stored here because their inner content is generated by the platform rather than maintained as a custom HTML module.

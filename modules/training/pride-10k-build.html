Pride 10K Build

An 8-week training program to run a faster 10K

We’re excited to offer an eight-week group coaching program for the Pride Run / Gay Games 10K, beginning May 4, 2026.

Who This Is For

  • Intermediate runners who have completed a few 10K races
  • Runners consistently completing about 15–25 miles per week

Schedule

  • Monday, 6:30 PM: Track workout at Kezar Stadium
  • Tuesday, 6:30 PM: Weekly Embarcadero run
  • Thursday, 6:30 PM: Weekly Castro run
  • Saturday, 9:00 AM: Weekly Blue Heron Lake run

Coach

Devesh is an RRCA-certified running coach with more than 20 years of experience racing distances from 5Ks to ultramarathons.

Cost

Free for all SFFR members and Pride Run registrants.

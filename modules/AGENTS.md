# Weekly Footweb updates

For each new Footweb issue:

1. Add the issue's new member spotlight to `membership/member-spotlight.html`. Preserve earlier spotlights and avoid duplicating an entry when revising the same issue.
2. Create `home/home-member-YYYY-MM-DD.html` using the newsletter's publication date. Keep the module order: Welcome Back, this week's Footweb, then Member Actions.
3. Update `home/home-member.html` with an exact copy of the newest dated member-home module. Verify the two files are byte-for-byte identical.
